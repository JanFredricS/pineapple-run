# Pineapple Run

A modern browser-based physics building game inspired by the classic Flash-era
*Coconut Run* (Johnson Controls advergame). Build a delivery vehicle out of
straws and drink-themed parts, load it with pineapples, and run it across
procedurally generated terrain without losing your cargo.

## Status

Early concept / research phase. See `research/` for reference material on the
original game and technology evaluation.

## Planned

- Vehicle builder phase (2D physics-based construction)
- Test/run mode with live physics
- Procedural map generator + hand-authored map builder
- 3 premade levels with distinct themes (beach, kitchen bench, workbench)
- Web app, desktop + mobile landscape, statically hosted
