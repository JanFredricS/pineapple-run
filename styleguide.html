Pineapple Run — style guide

Every S4 asset rendered through the production pipeline (SVG → rasterised atlas → Pixi v8), the four terrain/parallax themes, the blender goal loop, and a snapshot-driven motion test. Loading…

Parts & goal

Each asset at 0.5×, 1× and 2× (1× = 30 px per metre at zoom 1, i.e. in-game size). Straws and sugar cubes are built at arbitrary lengths/sizes the way the scene builds them (tiling straw body + end caps, nine-slice cube). The coil-spring shock (Hawthorne-strainer coil) cycles through compressed → rest → stretched. The blender loops fill + whir.

Themes

Same terrain sample (slopes, a kicker and a gap) skinned by each theme: tiled fill + depth shade + edge strip, over the 3–4 parallax layers. The camera pans slowly so the parallax is visible.

Motion test

A kinematic snapshot source (S0 MockSnapshotSource pattern) drives a real CartDesign through resolveAttachments — manifest + per-frame transforms only. “Live physics” runs the S0 spike (box2d, 12-straw cart, 15 pineapples) through the same renderer; drive with ← / →.

Atlas

Packed sprite atlas page(s) as baked at this device's raster resolution. Repeating textures (terrain, parallax, straw stripes) are standalone so the GPU can wrap them.
